# D03：原意图、执行与稳定阶段

本增量复用 [LaneChangePolicy](behaviors/lane_change.py)、BehaviorSession、
[正式候选适配器](behaviors/environment.py)和[换道生成器](../planning/LANE_CHANGE_CANDIDATES.md)。
正式感知已可连续调用这些组件；生产协调器仍只读取候选诊断，自动动作选择
仍待接入。固定规划入口已有[显式模型下的阶段消费者](../planning/LANE_CHANGE_DISPATCH.md)，
默认没有模型适配器或新增能力。实际灯光、模型标定、现场与
评分验收仍待验证。

## 选择和保持

初选继续要求实际邻道边界、合法原方向许可、同向关系和正式 Sensor 覆盖。
适配器记录原源道、目标道、逻辑侧及地图 MD5，选择后冻结这些身份。
`lane_candidates(..., active_candidate=policy.selected)` 可在目标成为 SDK
当前道后继续刷新原目标及 A→B 依据，不改选 B→A。另一车道或地图不能替换
当前意图，当前目标道也不能用于新建换道意图。

`evaluate` 的 `speed_cap_mps` 由上游明确授权，初次缺少正上限不创建动作。
实际车速为零不是速度授权为零：省略后续上限保留上次授权，显式零撤回
移动，新的正授权才可恢复。阻塞请求保持零速；恢复保留原意图及累计有限
重验次数，并重新请求路径，避免把停车后的零速写成永久零速目标。

可显式提供既有 `GoalPose` 后轴终点，初选时复制并冻结，跨阶段和恢复保持。
活动中的新动作/新终点必须先取消。修改可变请求对象的源道/目标/位姿会撤下
派发并恢复原绑定。未提供位姿的旧独立调用可继续试验，正式路径消费者须有
明确终点约定；策略不从题号制造终点或路径。

## 执行和稳定

执行前保留初始跨线机会窗口、前后间隙及真实灯光确认要求。执行开始后仍查
新鲜来源、原方向许可和对象间隙，但不再要求一次完整初始动作的预检查窗口。
剩余实际路径仍须通过 P02 连续整车跨线、可见区域、预测和期限检查；机会
检查不能代替可行路径，也不能使短许可自动可用。

目标已为 SDK 当前道，且本帧整车进入目标真实边界后，不再索取另一次换道
许可。此时同向但尚未达到稳定朝向容差的车身可继续受检回正；完成仍使用原
严格朝向与稳定帧要求。缺失原许可可保留当前目标几何，固定规划入口以 P02
核验全程在目标道内的剩余路径，跨线中的车身仍要求原许可。覆盖/目标/地图
失效仍撤回，当前车身与对象包络仍查占用；未来预测避碰仍由规划负责，结束
换道不解除普通跟车、信号或运行监护。

完成需要当前 GPS 车身和匹配实际执行反馈都完整进入目标道、方向正确并连续
稳定。车道 ID、规划确认或旧位姿不能完成。缺失/重复反馈、暂停、安全中断、
长观察间隔或无能力清掉稳定计数，反馈仍经过身份/阶段/修订/时钟/期限检查。

对象保留原观察位置和年龄，按恒速推进到本帧，策略显式加速度不确定范围
扩展至“原年龄 + 机会时窗”。这是策略模型，不证明真实误差界，也不代替
P02 的逐对象预测时限/误差及响应标定。

## 公共协议和验证边界

公共 BehaviorGoal 追加可选 `source_lane_id`，非空时须有不同目标道；参与
语义修订并在阻塞时保留。仅非空写入既有 v1 平面请求，原前进/信号字典形状
保持。旧前进/信号规划边界明确拒绝非空扩展，不能静默忽略后走普通前进。
固定终点复用既有 `goal_pose`，公共 JSON 回放/反馈继续保留原期限。

[新增离线回归](../../tests/test_decision_lane_transition.py) 连续调用实际环境生产者、
正式读取器、既有决策阶段、实际生成器及含转向迟滞的控制模型，保持原意图/
源道/目标/终点至 EXECUTE→SETTLE→完成；另覆盖 LHT 反向采样右灯、许可/
覆盖失效、位姿不一致、目标篡改、零速恢复、有限重验与中断。灯光确认/能力、
地图、Sensor 覆盖及响应均为明确合成输入，连续模型统一虚拟时钟。
生产自动任务/阶段选择、结束后轨迹/曲率衔接、取消恢复路径及完整 D01–D09/P01–P09、
视觉、现场和官方验收范围仍在继续。
