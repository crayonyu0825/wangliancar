## M1：最小完整慢车换道

生产 `decide()` 已调用 `RuntimeCoordinator`。有效新帧中，自由流速度比前车速度高出配置差值并持续达到门槛，且没有适用规则停车/来源失效时，才产生超越机会。候选必须有正式任务路线证据、同向地图几何、有限可跨范围及前侧后覆盖证明；选定后保持目标。方向灯准备以命令成功发送证据累计，不能把方向标志或车辆发送成功单独当作灯具实测。

正式执行链是 `PREPARE → EVALUATE_ONLY → EXECUTE_SELECTED`。规划评估时返回候选反馈，候选横向点列不送控，仍执行本车道跟车及灯光。决策采纳仍新鲜的候选后明确修订授权；规划当帧核对候选原评估身份、共同车型、来源、地图、权限、目标及整车路径，再输出实际横向轨迹。同段保持稳定身份，速度更新/前缀修正不创建新任务；已采纳段的灯光修订仍需当前重验。不同段/目标必须新评估，首次采纳不接受过期候选。

生产规划用当前位置与航向连续修正剩余路径，检查车身扫掠、曲率、速度/加减速度及转向率。前车仍与本车身走廊重叠时，当前速度意图和 v(s) 都保留前车速度上界，避免控制预瞄未来高速段提前压缩净距。整车进入目标走廊后才释放超越速度。达到邻道不等于超越完成：两车整车纵向包络通过并保留业务间隙后，才按任务需要重新评估返回；实际全车归属、航向与连续稳定证明完成。

执行中缺少环境、地图/权限撤销或被拒绝，进入保护与有界重验；不能直接用旧中心线导致突然回摆。红灯、危险及来源约束继续优先。帧回退保留活动目标，恢复修订重验；同 session 的标签改变不能清除活动任务。

## 共用公共通道

| 通道 | 生产者 → 消费者 | 实际语义 |
| --- | --- | --- |
| `core/behavior_protocol.py` | 全链共享 | 唯一运行版本 `joint-behavior-runtime-v1`，SDK 独立；旧独立策略导入路径为兼容包装 |
| `Perception.session_id/observed_at_s/observation_mode` | 感知/运行 → 全链 | 显式单进程单调时钟；队长真实任务变更生成新 session；生产默认拒绝模型输入 |
| `Perception.behavior_environment` | 感知 → 决策/规划 | 地图走廊、跨线范围、原始时间/有效期、覆盖证明、任务路线；未知保持未知 |
| `Perception.behavior_capabilities` | 规划注册实现 → 决策 | 真实已实现生成器与共同车型；与空白支持标志区分 |
| `DecisionTarget.behavior_request` | 决策 → 规划 | 目的、阶段、稳定修订、目标、约束身份及明确候选授权 |
| `Trajectory.planning_feedback/execution_path_id` | 规划 → 运行 → 决策 | 评估/拒绝和候选关联；不证明实际完成 |
| `ControlOut.execution_feedback` | 控制 → 运行 → 决策 | 当前实际位姿/速度、停稳、实际行驶进展及停留状态；降级轨迹不冒充执行候选 |
| `BehaviorExchange` | 运行 | 上一周期反馈供给本周期决策；本周期反馈保存到下一周期，拒绝错误/未来/过期/重复身份 |

原有四个 `DecisionMode`、固定三个入口、Python 3.6 和单进程链保持。没有 ROS。快照只作诊断，不形成反馈环；新增 `behavior_state` 能查看活动阶段/原因，不能作为执行输入。共享发送/安全开关保持原值，模型测试只在临时配置与模拟 SDK 下开启发送。

正式观察扩展由适配层显式 `behavior_observation_provider` 提供 detached 字典，感知拥有解析/质量门控。头部必须是本进程时钟、来源帧、原始观察时刻和截止时间；缓存结果不能获得新截止。生产 sensor 覆盖必须关联实际目标来源，融合覆盖必须声明正式输入来源。`proof_kind=sensor_fov_occlusion_validated`、覆盖区域、前侧后 scope、证明 ID、预测期限及不确定性是必需事实；量程、源名称和空对象列表不能补成证明。地图当前真实邻道样本已查询，但原 SDK 的局部标线不能外推为整个换道虚线范围，所以默认跨线范围未知。

模型观察只接受 `observation_mode=model` 与 `source_kind=synthetic`，实际 builder 还要求模型 SDK 标识；正式生产默认不启用。样例/替身不冒充正式 Sensor 数据。本机未取得平台侧后覆盖、整段跨线权限及当前实例响应证据；软件路径已接通，现场能力和评分仍未验收。

## 参数与证据

慢车持续门槛 2 s、自由流差值 1.5 m/s、灯光准备 1 s、稳定 3 个新帧；规划换道最短 22 m、预估 5 s、采样 0.5 m、验证预算 40 ms、试验转向率 0.8 rad/s。都可显式配置，属于模型/工程初值，不是现场标定值。跟车净距和静态余量从决策设置传递，各自保持业务语义。

`tests/test_joint_behavior_m1.py` 的正例使用真实固定入口，全部算法输出未经替换；独立车辆模型实际换出、超越、返回并由真实生产状态确认完成。当前基准模型最小跟车净距 **12.60 m**，完成约 **35.85 s**，返回时通过余量 **41.43 m**，最终横向位置约 **0.149 m**。模型中只含一辆慢车，不能由此推定复杂动态场景已通过。

同文件另跑真实感知 builder、运行、监护与原生发送器，只替 SDK 输入输出/地图及车辆模型，实际完成换道超越和返回。反例检查评估候选不送控、过期/错误候选拒绝、覆盖未知、模型来源在生产拒绝及红灯不触发超越；测试直接核对物理净距与位姿，不能只以状态常量通过。
