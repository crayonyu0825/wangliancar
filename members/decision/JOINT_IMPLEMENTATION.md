## M1：最小完整慢车换道

生产 `decide()` 已调用 `RuntimeCoordinator`。有效新帧中，自由流速度比前车速度高出配置差值并持续达到门槛，且没有适用规则停车/来源失效时，才产生超越机会。候选必须有正式任务路线证据、同向地图几何、有限可跨范围及前侧后覆盖证明；选定后保持目标。方向灯准备以命令成功发送证据累计，不能把方向标志或车辆发送成功单独当作灯具实测。

正式执行链是 `PREPARE → EVALUATE_ONLY → EXECUTE_SELECTED`。规划评估时返回候选反馈，候选横向点列不送控，仍执行本车道跟车及灯光。决策采纳仍新鲜的候选后明确修订授权；规划当帧核对候选原评估身份、共同车型、来源、地图、权限、目标及整车路径，再输出实际横向轨迹。同段保持稳定身份，速度更新/前缀修正不创建新任务；已采纳段的灯光修订仍需当前重验。不同段/目标必须新评估，首次采纳不接受过期候选。

生产规划用当前位置与航向连续修正剩余路径，检查车身扫掠、曲率、速度/加减速度及转向率。前车仍与本车身走廊重叠时，当前速度意图和 v(s) 都保留前车速度上界，避免控制预瞄未来高速段提前压缩净距。整车进入目标走廊后才释放超越速度。达到邻道不等于超越完成：两车整车纵向包络通过并保留业务间隙后，才按任务需要重新评估返回；实际全车归属、航向与连续稳定证明完成。

执行中缺少环境、地图/权限撤销或被拒绝，进入保护与有界重验；不能直接用旧中心线导致突然回摆。红灯、危险及来源约束继续优先。帧回退保留活动目标，恢复修订重验；同 session 的标签改变不能清除活动任务。

## M3～M5 联合落地补充

### 泊车与通用义务（M3 / D01、D04 / P04、P07）

`ParkingRuntime → ParkingPlanner → ControlEngine` 已接入固定入口。车位必须为当前已观察空位且整车能放下，车身中心到后轴的偏移参与最终姿态计算。目标按距离和稳定 ID 选择；搜索器从实际后轴位姿计算接近、调整、停点及正反向段，输入不要求手写 approach/position/exit 点列。

搜索先尝试通过车身检查的平滑直连或圆弧—直线—圆弧，再作有节点/时间上限的双向自行车搜索。每个方向段及曲率切换段都有独立实际停稳终点；只有上段实际到位、停稳、反馈身份匹配才授权下一段。搜索时限覆盖初始/目标和解析分支的车身检查；超预算给拒绝反馈，实际出口继续制动。每帧按实际姿态/速度修正剩余路径并重验整车、边界、全部目标和时间包络。

最终入位同时核对姿态、实际静止和全车在车位内。最终段带稳定 `parking:<task_id>` 义务及至少 10 s 停留；控制计时完成后才重新评估任务规定的驶出目标。自身占位需要可信主车目标 ID 及当前车身与车位关系；匹配自车目标还核对其位置是否在实际车身中心附近，其他目标继续验障。倒车只在明确的已授权反向段执行；原始 GPS 挡位仍不解释成控制枚举，等待联锁只表示命令准备，真实挂挡证据未取得。

帧回退保留选位/任务/停留义务，并作废旧候选、从当前位姿重新搜索。应急打断时暂停原泊车意图；恢复后搜索新路径，原车位和驻留义务保留。完成后输出当前已停稳位姿的保持轨迹，避免用不再适用的旧车道中心线作停车目标。

信号特殊停留由正式任务规则提供时长和严格语义，普通红灯/跟车停车不自动添加。严格 >5 s 在请求中使用 5.001 s，>=10 s 使用 10 s。早变绿仍保留未完成义务；控制只从到位、姿态一致、连续静止观察计时，漂移或中断重计连续时间。同一已完成义务 ID 不重复开始，新的义务 ID 即使位置相近也独立生效。

受阻警示使用真实静障停止约束及无当前可执行替代动作的事实；正常跟车和规则停车排除。实际制动/双闪接线后，按覆盖完整的新鲜清空帧解除；实际已经在合法停止上界前保持的等待允许持续警示，不把等待当作执行卡死。灯光证据仍是命令发送等级。

### 路口、横穿和出口准入（M4 / D05～D07 / P06）

`IntersectionTask` 给出已选有限路线、入口/出口路线站位、真实冲突区、可行驶区、出口区、规则及绝对时钟权限窗口。决策按实际全车沿这条路线的站位区分入口前、内部及已驶离；规划/监护使用共用的精确非凸轮廓，凹陷不取凸包填平。

每个目标按当前占用及有界预测扫掠占用冲突区；时间窗含早到/晚到、位置/速度不确定性及安全扩张。规则、信号、预测覆盖和权限窗口先交集，再扣除占用窗口。决策只作粗机会判断；规划验证从车头进入到车尾离开的整个自车区间，覆盖剩余路线、所有目标及出口空间。`PLANNED` 的窗口不会直接放行：必须采纳仍新鲜的候选，并在执行各帧及运行监护复核。

出口按沿路径连续可摆放整车及业务间隙的范围检查，不能只有出口点或半车空间。入口前不能准入时发布真实线前停止轨迹；已经进入后撤权/新阻断时保持制动保护，停止目的不再回套车后入口线。实际车尾越过出口且全车在出口区连续两个新帧才记 `EXITED`。目标短时消失保留 0.5 s 折返保护及覆盖清空确认；新目标/ID、窗口或覆盖失效撤销授权。新的已核实占用→清空变化可有限重启评估，不能由重复反馈或时间流逝无限刷新重试。

### 应急候选与任务进度（M5 / D08、D09 / P08、P09）

危险当周期保留原紧急制动。`EmergencyPlanner` 在明确允许区域和横移权限内生成制动、左/右转向加制动候选，检查完整车身、运动/转向率及动态目标；评估路径只作为反馈。危险身份、权限、来源或当前路径改变时旧采纳失效，未知/不可行/超预算继续急刹。

候选排序先比较风险代理，再比较最小间隙下界、规则代理和稳定 ID。当前可执行候选均须取得连续无碰撞证书，因此风险代理为 0；规则代理是横移幅度。失败候选不作为可执行无碰撞动作。全部失败时使用已有最大急刹出口，报告具体拒绝原因；这不证明不可避免碰撞下的全局最优风险或无碰撞。车辆质量、未知意图和真实响应不足，相关严重性标定仍待实例数据。

公共 `Trajectory.emergency_maneuver_authorized` 默认 false；只有当前 `EMERGENCY + EXECUTE_SELECTED`、对应候选和递减至零的制动剖面才允许 true。控制保留同一校准紧急刹车、零油门、空挡，并跟踪转向。运行监护仍执行原来源/GPS/车道/信号/TTC/紧急检查；原紧急出口保留同一紧急刹车，只对当前候选通过共用整车复核时保留已验证转向。没有跳过旧碰撞或车道检查。没有采纳、过期、数据失效或反向运动时仍是原制动出口；当前主动应急转向生成器只支持前向，倒车危险继续即时制动。

运行交换使用实际送出的监护控制；受监护复核的应急动作仍只回传本帧实际位姿、速度和进展，不把发送回执当作到达证据。危险解除要求新鲜完整覆盖和实际停稳，再发出新的原路线恢复评估/授权。已偏离的模型真实驶回路线才完成；已位于允许路线姿态内时确认当前整车关系。原换道/泊车任务保留，后续重新准备/评估路径。

`TaskRouteFacts → TaskProgressPolicy → TaskRuntime` 接入正式路段序列、当前段、可达进度及参考结束原因，记录临时动作恢复锚点。拒绝不可达进度、未来/返回段跳跃及同 session 的路段定义改变。局部窗口、地图末端、分叉歧义或查询失败都受有限参考前的整车停止上界保护，不能记任务完成。实际终点完成须为最终规定段、实际目标姿态/停稳、全车在目标区和所需义务已完成。帧回退保留任务及义务，明确新 session 才清理。
