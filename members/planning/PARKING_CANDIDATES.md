# 泊车与驶出候选：当前实现及接入边界

本增量基于 main `aa65aeb` 之后的行为感知分支。它生成实际位置、车身朝向、
速度与时间点，复用 [P03 连接曲线](lane_change_generator.py)、
[P02 连续整车校验](CANDIDATE_VALIDATION.md) 和已有双向控制器。
固定规划入口现已支持显式模型/任务提供者下的 PARK 阶段消费，见
[阶段派发与实际反馈](PARKING_DISPATCH.md)。默认没有提供者，运行能力仍仅为
`PATH_STOP/DWELL/FEEDBACK`，真实生产任务与来源接入继续进行。

## 输入与生成

[generate_parking_segment](parking_generator.py) 接受后轴起点及目标位姿、
实际初速、显式初始曲率、运动方向、整车几何、运动限制、速度上限、道路与
车位约束、完整可见区域、有限预测以及统一工作预算。没有场景固定坐标、
默认车型或用目标朝向替代未知地图朝向。

- `APPROACH/POSITION/EXIT` 是前进段；`REVERSE_ENTRY/ALIGN` 是倒车段。
- 每段只使用一个方向，速度为非负幅值，朝向是车身朝向，倒车时行进方向相反。
- 保留实际起始速度，末端速度为零，距离、加减速与相对时间一致。
- 使用有限组五次 Hermite 曲线；起点和终点切向长度可独立调整，支持平行与
  垂直车位。可显式提供末端直线长度，默认零长度保持原候选；所有切向、
  速度及直线组合总数不超过 64。搜索失败不证明不存在其他路径，也不会把
  失败候选当成可行路径。
- 逐一检查转向/转向变化率、几何与朝向曲率、整车连续扫掠、动态目标、可见
  区域和目标整车容纳。所有生成、候选和校验共用预算，超限撤销点列。

结果的 `nominal_candidate_only` 只适用于给定平面、插值、预测和误差模型。
它不能证明真实车辆能精确跟踪，也不产生实际到点、连续停留或行为完成反馈。

## 正式车位来源与入口

[ManeuverFacts.parking](../../core/maneuver_facts.py) 核对当前地图摘要、SDK 车位
目录读取完整性、唯一车位 ID、原始四角/前边缘/高度、正式环境中的相同几何、
完整 Sensor 观察、独立期限、空位证据及完整可见范围。公共 JSON 回放保留这些
来源；缓存只复用静态几何，不续期动态证据或安全结果。

[read_parking_scene / plan_parking_candidate](parking_scene.py) 使用当前已知车道
与邻道的真实轮廓和车位组成显式并集，不用凸包填补车道与车位之间的空隙。
当前来源适配仍要求已知当前车道；尚未实现无车道停车场/通道的正式几何生产者。

既有决策阶段已补[正式车位/道路并集适配](../decision/PARKING_EXECUTION.md)，
复用本生成器的原几何引擎，整车选位与后轴目标可直接作为 P04 输入。接近/
预入/驶出姿态和入口仍由经过核对的任务来源明确提供。PARK 消费者重查原
阶段与新鲜实际反馈，支持剩余段重计时、原到位区域收尾；这些显式接线不能
认作默认生产泊车已启用。

`access_edge_index` 必须由调用方明确提供。SDK 的 `a-d` 前边缘只是原始几何，
不能默认它就是平行车位的入口。选定边缘作为本次候选的名义开口，其余三边
按调用方约束保持关闭；这不是把所有车位涂漆解释成实体墙，也不建立交通通行权。
车位和道路并集本身不能授权进出。生产接入仍需有来源的入口/通道与规则依据。

原目标年龄会推进目标预测位置，并缩短有限预测时限；位置和速度误差必须显式
提供。生成结束再次核对来源期限、地图/当前车道和原车位几何，失效即撤销点列。

## 控制联调发现及修复

保留的泊车轨迹从实际零速开始。原控制器只在路径进度不超过 `1e-6 m` 时做
起步预瞄；车辆刚移动，参考速度便回到起点附近的低值，可能重新进入 `HOLD`。
现于 [PreparedPath](../control/trajectory.py) 将预瞄限制在原轨迹**初始非递减
速度段**内，并允许随实际进度继续预瞄。预瞄距离、加速度、全局速度、曲率、
路径末端及停止距离仍分别限幅；第一次减速或中途零速后不会重新越过约束。

这项控制修复同时适用于前进和倒车，并未伪造正的起始速度。控制按空间速度
跟踪，含起步预瞄和实际滞后，不能将候选相对时间当作真实执行时间。动态安全
还需跟踪/时序误差依据和连续重规划。

## 验证与后续

[泊车回归](../../tests/test_planning_parking_generator.py) 覆盖平行/垂直倒入、
前进驶出、显式入口、车位外道路、整车目标、后方侵入、未知朝向、可见孔洞、
时效/地图变化、预算和 JSON 回放。生成后的点列直接交给实际 `ControlEngine`，
使用带滞后的离线车辆模型验证倒入、实际停稳、连续 10 秒停留、换向互锁及驶出。
另有 [控制回归](../../tests/test_control_planning_sampling.py) 检查微小进度后的
持续起步、点密度变化、减速及中途停车约束。

这些是合成来源和车辆模型的离线验证，没有实际 SimOne 或官方评分结果。
本增量新增泊车/来源/连续控制 31 项和通用控制起步回归 2 项。最终生产代码在
SimOne Python 3.6.4 下完整 discover：**1094 项通过，0 失败、0 跳过，266.101 秒**；
Python 3.6 语法与文档链接检查通过。
阶段切换须继续复用现有决策状态机和实际控制反馈，不由生成器推进。后续仍需
正式入口与停车通道来源、多次换向修正、
取消恢复、实际 Sensor 覆盖、车型/响应依据和授权后的现场验收。
