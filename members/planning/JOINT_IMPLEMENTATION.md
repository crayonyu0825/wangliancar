## 实际注册生成器

| 规划能力 | 代码 | 当前消费 |
| --- | --- | --- |
| P01/P03/P09 | `behavior_planner.py`、`lane_planner.py` | 有限路线、连续换道/绕障/汇入、超越延续与返回；任务终点/参考边界停止 |
| P02/P05 | `core/trajectory_validation.py` | 整车连续扫掠、精确非凸道路、所有目标及早/晚时间包络；旧 `candidate_validation.py` 保留兼容导入 |
| P04 | `parking_search.py`、`parking_planner.py` | 有界双向自行车搜索及通过车身检查的解析连接；实际逐段方向、停点和当前重验 |
| P06 | `intersection_planner.py` | 已选路口路线、线前等待、完整车头进入～车尾离开区间、当前出口/时间窗口重验 |
| P07 | 停止/保持与各生成器 | 精确停车、稳定义务 ID、最短驻留与显式灯光；实际完成由控制反馈 |
| P08 | `emergency_planner.py` | 立即制动与前向制动/转向加制动候选；当前允许区/权限/全部目标及明确采纳；失败保留急刹 |

能力注册有共同车身/轴距/转向几何和当前上下文。停车、路口、应急与换道生成器都核对该几何及实际注册能力；未获得来源、权限、覆盖和时间界会拒绝动作。当前主动应急转向只支持前向，反向危险使用已有即时制动。

评估只返回候选反馈，控制继续接收合法停止/保持轨迹。首次执行必须采纳仍新鲜且身份匹配的候选；继续执行要逐帧从实际姿态/速度重验，不能给旧点列换帧续命。停车仅授权当前段；新的方向/段需要实际到位停稳。路口复核覆盖全车通行区间；应急明确采用制动剖面，油门保持零。

监护共用 SDK 独立的几何验证器作当前输入复核。原碰撞、来源、车道和信号检查仍生效；应急复合动作保留原紧急制动，只在明确的当前采纳路径验证通过时保留转向。四个公共决策模式、单进程调用链、发送开关和 Python 3.6 技术约定保持。

## 证据与范围

M1 的固定入口及真实运行/原生发送器模型完成慢车换出、超越、返回；M2 有实际弯道超越、绕障、合流和时间误差/取消/覆盖反例。M3 平行/垂直实际入位、至少 10 s 驻留和驶出；M4 实际入口等待、群体/折返及整车驶离；M5 有真实制动+转向、危险解除后新评估及实际回归、有限参考与真实终点。详细结果及未验收项以共同交付页为准。

当前证据为离线模型和公共合同接线。车型响应、环境时间界、真实覆盖/权限生产及 SimOne/评分仍需实例数据；动态预测的恒速/固定朝向和显式不确定性有适用边界。保留旧独立组件记录，后续接手以这份实际生成器表及共同交付矩阵为准。
